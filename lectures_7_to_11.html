Lecture 7

Major Theorems of Multivariable Calculus: Taylor's Theorem, Inverse & Implicit Function Theorems, Envelope Theorem, Constrained Optimization

Section 1 — Taylor's Theorem (Multivariable)
Theorem 7.1 — Taylor's Theorem (Multivariate)
Let f : U → ℝ (U open in ℝᴺ). Suppose U contains the segment from a to b (a ≠ b), and f is r times differentiable. Then ∃q on the segment (q ≠ a, q ≠ b) such that:
f(b) = f(a) + Df(a)(b−a) + (1/2)D²f(a)(b−a,b−a) + ⋯ + (1/(r−1)!)Dʳ⁻¹f(a)(b−a,…,b−a) + (1/r!)Dʳf(q)(b−a,…,b−a)
where the last term is the remainder at some interior point q.

Expanding the terms explicitly:

Df(a)(b−a) = Σₙ ∂f(a)/∂xₙ · (bₙ−aₙ) D²f(a)(b−a,b−a) = Σₘ Σₙ ∂²f(a)/(∂xₘ∂xₙ) · (bₘ−aₘ)(bₙ−aₙ)
Theorem 7.2 — Remainder Vanishes
If f is r times continuously differentiable, the remainder R(a,b) = (1/r!)Dʳf(q)(b−a,…,b−a) satisfies: R(a,b)/‖b−a‖ʳ⁻¹ → 0 as b → a.
Theorem 7.3 — Second Order Conditions
Let f : U → ℝ, twice continuously differentiable, with Df(c) = 0. If D²f(c) is negative definite, f has a local maximum at c. If D²f(c) is positive definite, f has a local minimum at c.
Proof: By Taylor's theorem, f(x) = f(c) + (1/2)D²f(q)(x−c,x−c). Negative definiteness of D²f(q) near c makes this negative, so f(x) < f(c).
Section 2 — Inverse Function Theorem

The inverse function theorem says that if Df(c) is invertible, then f has a local inverse near f(c). The derivative behaves locally as an invertible linear transformation.

Theorem 7.4 — Inverse Function Theorem
Let f : U → ℝᴺ (U open in ℝᴺ), f continuously differentiable, and Df(c) invertible at c ∈ U. Then ∃ open V ⊂ U containing c such that W = f(V) is open, ∃ continuously differentiable g : W → V with f∘g(w) = w and g∘f(v) = v for all w ∈ W, v ∈ V. Moreover, if v ∈ V:
Dg(f(v)) = (Df(v))⁻¹
Example
Let y = (x⁵+eˣ)/(1+x)². At x=0, y=1 and the derivative = −1 ≠ 0. By the inverse function theorem, x is locally a function of y near (x,y)=(0,1), and dx/dy = 1/(dy/dx) = −1.
Section 3 — Implicit Function Theorem

For linear functions: if T : ℝᴺ⁺ᴷ → ℝᴷ has K independent columns (full rank K), write T = (A|B) where B is K×K invertible. Then z = Ax + By → y = B⁻¹(z−Ax). The equation z = T(x,y) defines y as a linear function of (x,z).

The implicit function theorem extends this to nonlinear functions locally:

Theorem 7.5 — Implicit Function Theorem
Let Q be open in ℝᴺ⁺ᴷ, f : Q → ℝᴷ continuously differentiable, (a,b) ∈ Q (a ∈ ℝᴺ, b ∈ ℝᴷ), and the last K columns of Df(a,b) independent. Then ∃ open U ∋ a in ℝᴺ, open V ∋ c=f(a,b) in ℝᴷ, and continuously differentiable h : U×V → ℝᴷ such that f(x,h(x,z)) = z for all x ∈ U, z ∈ V, with h(a,c) = b. Also:
Dₓh(a,c) = −(D_y f(a,b))⁻¹ Dₓf(a,b) Dᵤh(a,c) = (D_y f(a,b))⁻¹
Circle Example
f(x,y) = x² + y², equation f=r². If |x̄|<r̄ and x̄²+ȳ²=r̄², then ȳ≠0 so ∂f/∂y=2ȳ≠0. By IFT, y is locally a function of x and r: either y=√(r²−x²) or y=−√(r²−x²).
Derivative Formulas via Chain Rule
Differentiating f(x,h(x,z))=z w.r.t. x: Dₓf + D_y f · Dₓh = 0 → Dₓh = −(D_y f)⁻¹Dₓf. The IFT formula follows directly from the chain rule applied at the solution point.
Section 4 — The Envelope Theorem (Unconstrained)

Consider max_{x∈ℝᴺ} f(x,b) where b ∈ ℝᴷ are parameters. Let F(b) = max_x f(x,b) (assuming the max exists). The envelope theorem says:

The Envelope Theorem
Assume f is twice continuously differentiable, Dx²f(x,b) is negative definite for all (x,b), and x=h(b) solves Dxf(h(b),b)=0 (by IFT, h is continuously differentiable). Then:
DF(b)|_{b=b̄} = D_b f(h(b̄), b)|_{b=b̄}
To find how the maximized value changes in b, evaluate the partial derivative of f w.r.t. b at the optimum — you do NOT need to account for how the maximizer x changes with b.
Why? The Intuition
At the maximum, Dₓf = 0. So the "indirect effect" via x is: Dₓf · Dh = 0. Only the direct effect of b on f survives. This is why the formula is so clean.
Profit Maximization Example
Firm: π(p,w) = max_L [pf(L) − wL]. The envelope theorem gives:
∂π/∂w = −L(p,w) (Shephard's Lemma: wage derivative of profit = −labor demand) ∂π/∂p = f(L(p,w)) (price derivative of profit = output supply)
These are fundamental results in producer theory.
Section 5 — Constrained Optimization (Lagrange Multipliers)
Theorem 7.6 — Lagrange Multiplier Theorem (Necessary Conditions)
Consider max_x f(x) s.t. gₖ(x) = āₖ for k=1,…,K (U open in ℝᴺ). If f achieves a local max/min at x̄ and the constraint qualification holds (Dg₁(x̄),…,DgK(x̄) are independent), then ∃λ₁,…,λK such that:
Df(x̄) = Σₖ λₖ Dgₖ(x̄)
The λₖ are Lagrange multipliers.
The Lagrangian
L(x,λ,ā) = f(x) − Σₖ λₖ[gₖ(x) − āₖ]
Setting D_{(x,λ)}L = 0 gives first order conditions (∂L/∂xₙ = 0) and constraints (∂L/∂λₖ = 0, i.e., gₖ(x)=āₖ).
Geometric Meaning
At the constrained maximum x̄, the gradient Df(x̄) must be a linear combination of the constraint gradients Dgₖ(x̄). Geometrically in 2D (K=1): the level curve of f through x̄ is tangent to the constraint curve g(x)=ā. The gradient Df points perpendicularly to the level curve, and Dg perpendicularly to the constraint curve — tangency means they point in the same (or opposite) direction.
Theorem 7.7 — Sufficient Conditions (Second Order)
Let Z(x̄) = {v ∈ ℝᴺ | Dg(x̄)(v) = 0} (the "constrained directions"). With λ from Thm 7.6 and the Lagrangian L:
  • If vᵀDx²L(x̄,λ,ā)v < 0 for all v ∈ Z(x̄), v≠0: local maximum at x̄
  • If vᵀDx²L(x̄,λ,ā)v > 0 for all v ∈ Z(x̄), v≠0: local minimum at x̄
Summary of Conditions
  1. Constraint: g(x̄) = ā (feasibility)
  2. First order condition: Df(x̄) = λᵀDg(x̄) (necessary)
  3. Second order condition: vᵀDx²L·v < 0 for v ∈ Z(x̄)\{0} (sufficient for max)
  4. Conditions 1+2+3 together are sufficient for local optimality
Lecture 8

Optimization: Convexity, Kuhn-Tucker Theory, Envelope Theorem for Constrained Problems

Section 1 — Convex Analysis
Definition: Convex Set
A subset A of ℝᴺ is convex if for every a,b ∈ A and α ∈ [0,1]: αa + (1−α)b ∈ A. (The line segment between any two points stays in the set.)
Definition: Concave Function
f : A → ℝ (A convex) is concave if for all a,b ∈ A and α ∈ [0,1]:
f(αa + (1−α)b) ≥ αf(a) + (1−α)f(b)
Strictly concave: strict inequality for a ≠ b, 0 < α < 1.
Definition: Convex Function
f is convex if f(αa+(1−α)b) ≤ αf(a)+(1−α)f(b). (f is convex iff −f is concave.)
Theorem 8.1 — Local = Global for Concave Functions
If A is convex and f : A → ℝ is concave, any local maximum of f is a global maximum.
Theorem 8.2 — Uniqueness for Strictly Concave
If f is strictly concave, f achieves a global maximum at at most one point.
Theorem 8.3 — FOC for Global Max (Concave + Differentiable)
If A is convex and open, f : A → ℝ is concave and differentiable: f achieves a global maximum at a ∈ A ↔ Df(a) = 0.
Theorem 8.7 — Second Derivative and Concavity/Convexity
If A is convex and open, f twice differentiable everywhere:
  1. f is concave ↔ D²f(x) is negative semi-definite for all x
  2. f is strictly concave if D²f(x) is negative definite for all x
  3. f is convex ↔ D²f(x) is positive semi-definite for all x
  4. f is strictly convex if D²f(x) is positive definite for all x
Note: negative definiteness of D²f is sufficient but not necessary for strict concavity (example: f(x) = −x⁴ is strictly concave but f''(0)=0).
Why Concavity is Central to Econ
Utility functions are assumed concave → the first order conditions (MU₁/p₁ = MU₂/p₂ = λ) are sufficient for a global maximum → demand is well-defined. Production functions often assumed concave → diminishing returns. If f is strictly concave, there is a unique maximizer → unique demand, unique equilibrium.
Section 2 — Kuhn-Tucker Theory (Inequality Constraints)

Extends Lagrange multiplier theory to inequality constraints. Consider:

max f(x) s.t. gₖ(x) ≤ āₖ, for k=1,…,K x∈C

where C ⊆ ℝᴺ is non-empty and convex, f : C → ℝ is concave, each gₖ : C → ℝ is convex.

Feasibility and Complementary Slackness

x ∈ C is feasible if gₖ(x) ≤ āₖ for all k.

Complementary slackness: λₖ = 0 if gₖ(x̄) < āₖ. (A non-binding constraint has zero multiplier.)

The Lagrangian: L(x,λ) = f(x) − Σₖ λₖgₖ(x).

The numbers λ₁,…,λK are called Kuhn-Tucker coefficients. x̄ and λ satisfy the Kuhn-Tucker conditions if: x̄ is feasible, λ ∈ ℝᴷ₊ (non-negative), complementary slackness holds, and x̄ maximizes L(x,λ) over C.

Theorem 8.8 — Kuhn-Tucker Theorem

Sufficiency: If x̄ and λ ∈ ℝᴷ₊ satisfy the Kuhn-Tucker conditions (complementary slackness + x̄ maximizes L over C), then x̄ solves the constrained problem.

Necessity: If x̄ solves the problem and the constraint qualification holds (∃x ∈ C with gₖ(x) < āₖ for all k), then ∃λ ∈ ℝᴷ₊ such that the Kuhn-Tucker conditions hold.

Difference from Lagrange Multipliers
Lagrange multipliers: equality constraints, differentiable functions, multipliers can be any sign. Kuhn-Tucker: inequality constraints, concave/convex functions (no differentiability needed), multipliers are non-negative (≥0). KT is the workhorse of economic optimization — budget constraints, non-negativity constraints, capacity constraints are all inequalities.
Consumer Problem Example
max u(x) s.t. p·x ≤ w, x ≥ 0
KT conditions: ∂u/∂xₙ ≤ λpₙ with equality if xₙ > 0 (complementary slackness). Non-negativity: xₙ ≥ 0, μₙ ≥ 0, μₙxₙ = 0. Constraint qualification: x=0 satisfies p·0 = 0 < w (if w>0).
Section 3 — Dependence of Constrained Optima on Parameters

Continuing with max f(x) s.t. gₖ(x) = āₖ. How does the optimal x and Lagrange multipliers λ change as the constraint levels a = (a₁,…,aK) vary? The necessary conditions are:

Df(x) − λᵀDg(x) = 0 −g(x) + a = 0

Write this as H(x,λ,a) = 0. By the IFT, (x,λ) is a continuously differentiable function of a provided the bordered Hessian is non-singular:

D_{(x,λ)}H(x̄,λ̄,ā) = [Dx²L −(Dg)ᵀ] [−Dg 0 ]

This is the bordered Hessian. The second order conditions guarantee it is non-singular (rank N+K).

Lagrange Multipliers as Marginal Values
Let F(a) = f(x(a)) be the maximized value. By the chain rule and the envelope argument:
DF(a) = λᵀ(a)
So λₖ(a) is the rate at which the maximized value increases as constraint level aₖ increases. This is the "shadow price" of the constraint.
Section 4 — Envelope Theorem for Constrained Optimization

Consider max_x f(x,b) s.t. g(x,c) = a, with parameters a, b, c. Let F(a,b,c) = f(x(a,b,c),b). The envelope theorem (Bewley equation 8.6) states:

DF(ā,b̄,c̄) = D_{(a,b,c)} L(x̄, λ̄, a, b, c)|_{(a,b,c)=(ā,b̄,c̄)}

where L(x,λ,a,b,c) = f(x,b) − λᵀ[g(x,c) − a]. In component form:

Da F = λ̄ᵀ (shadow price: matches earlier result) Db F = Db f(x̄, b̄) (direct effect of b on objective) Dc F = −λ̄ᵀ Dc g(x̄, c̄) (effect via constraint function)
Cobb-Douglas Consumer Demand
Utility u(x) = Σₙ αₙ ln(xₙ). Budget: Σₙ pₙxₙ = w. FOC: αₙ/xₙ = λpₙ. At optimum:
xₙ = αₙ/λpₙ and Σ pₙxₙ = w → λ = (Σαₙ)/w → xₙ = αₙw/(pₙ Σ αₖ)
Each good's expenditure is a fixed fraction αₙ/Σαₖ of total wealth w. This is a fundamental result: Cobb-Douglas implies constant expenditure shares.
Lecture 9

Proof of the Kuhn-Tucker Theorem; Dynamic Programming I

Section 1 — Proof of Sufficiency (Kuhn-Tucker)
Theorem 9.1 — KT Sufficiency
Let C be a non-empty convex set, f : C → ℝ concave, gₖ : C → ℝ convex. Suppose x̄ ∈ C satisfies gₖ(x̄) ≤ āₖ, λ ∈ ℝᴷ₊ satisfies complementary slackness (λₖ=0 if gₖ(x̄)<āₖ), and x̄ maximizes f(x) − Σλₖgₖ(x) over C. Then x̄ solves max f(x) s.t. gₖ(x) ≤ āₖ.
Proof: Complementary slackness → Σλₖgₖ(x̄) = Σλₖāₖ. For any feasible x: f(x̄) − Σλₖāₖ = f(x̄) − Σλₖgₖ(x̄) ≥ f(x) − Σλₖgₖ(x) ≥ f(x) − Σλₖāₖ. Therefore f(x̄) ≥ f(x). ∎
Section 2 — The Value Function and Subgradients
Definition: Value Function
V(a₁,…,aK) = sup{f(x) | x ∈ C and gₖ(x) ≤ aₖ for all k}. The domain A = {a | ∃x ∈ C with gₖ(x) ≤ aₖ for all k}.
Lemma 9.2
The set A is convex and the value function V : A → ℝ is concave.
Definition: Subgradient
A subgradient of f : A → ℝ at a ∈ A is a vector λ ∈ ℝᴷ such that f(b) ≤ f(a) + λᵀ(b−a) for all b ∈ A. (Generalizes the derivative to concave, possibly non-differentiable functions.)
Subgradients and KT Multipliers
If f is concave and differentiable at a, the unique subgradient at a is Df(a). If f is not differentiable, multiple subgradients may exist (like different tangent lines at a kink). The KT coefficients λ are a subgradient of the value function V at ā — this is their economic meaning: each λₖ is the (generalized) marginal value of relaxing constraint k.
Theorem 9.3 — KT Coefficients are Subgradients of V
Under the KT conditions (x̄ satisfying complementary slackness and maximizing L), λ is a subgradient of V at ā.
Theorem 9.4 — Converse: Subgradients give KT Conditions
If λ ∈ ℝᴷ is a subgradient of V at ā, then λ ≥ 0, λₖ=0 if gₖ(x̄)<āₖ, and x̄ solves max f(x)−Σλₖgₖ(x) over C. (Subgradients of V are exactly KT multipliers.)
Section 3 — Minkowski Separation Theorem
Definition: Separating Vector
An N-vector p separates sets X and Y if p ≠ 0 and p·x ≤ p·y for all x ∈ X, y ∈ Y.

Geometrically: a hyperplane {x | p·x = r} separates X from Y, with X on one side and Y on the other.

Definition: Interior
int(X) = {x ∈ X | ∃ε>0: Bε(x) ⊂ X}. The interior of [0,1] is (0,1).
Theorem 9.5 — Minkowski Separation Theorem
Let X and Y be convex subsets of ℝᴺ. If int(X) is non-empty and does not intersect Y, then ∃ non-zero p separating X from Y.
Necessity of Convexity
Convexity of both sets is required. Non-convex sets that are disjoint may not be separable. Also, the interior assumption is needed: two convex sets that touch along a boundary (empty interior) may not be separable.
Lemma 9.6
If A is convex, f : A → ℝ is concave, and ā ∈ int(A), then f has a subgradient at ā. (Proven using Minkowski's theorem applied to the epigraph of f.)

The proof of the necessity of KT conditions uses Lemma 9.6 and Theorem 9.4: the value function V is concave (Lemma 9.2), ā ∈ int(A) (constraint qualification), so V has a subgradient λ at ā (Lemma 9.6), and by Theorem 9.4 λ satisfies the KT conditions.

Section 4 — Dynamic Programming I

The second part of Lecture 9 introduces dynamic programming (DP) to solve infinite-horizon optimization problems. Here Bewley introduces the setup:

The Infinite-Horizon Problem Setup

State space X ⊆ ℝᴺ (compact). Feasibility: G(x) ⊆ X is the set of states reachable from x in one period. Instantaneous utility u : A → ℝ, where A = {(x,y) ∈ X×X | y ∈ G(x)}. Discount factor 0 < β < 1.

A program starting at x₀ is a sequence (x₀,x₁,x₂,…) with xₜ₊₁ ∈ G(xₜ) for all t.

Objective: maximize Σₜ₌₀∞ βᵗ u(xₜ,xₜ₊₁).

The Bellman Equation
The value function: V(x₀) = sup of Σβᵗu(xₜ,xₜ₊₁) over all programs from x₀. The Bellman equation is:
V(x₀) = max_{x₁ ∈ G(x₀)} [u(x₀,x₁) + βV(x₁)]
The value today = best achievable: immediate utility + β × value from tomorrow.
Why DP is Powerful
Instead of optimizing over infinite sequences, DP reduces the problem to a single-period decision: given the state x₀, choose x₁ ∈ G(x₀) to maximize current utility plus discounted continuation value. The Bellman equation is a fixed-point equation: V is its own "one-period recursion."
Lecture 10

Dynamic Programming II: Euler Equations, Growth Model Example

Section 1 — Worked Example: Optimal Growth
Example 10.1 — Neoclassical Growth Model
Production function: y = F(K) = 2√K. Utility: v(C) = ln(C). Discount factor: 0 < β < 1.

Problem: maximize Σₜ₌₀∞ βᵗ ln(Cₜ) subject to Cₜ + Kₜ ≤ 2√K_{t−1} for t = 0,1,2,…

Euler Equation: Differentiating the Lagrangian with respect to Kₜ:

1/Cₜ = β · (1/Cₜ₊₁) · (1/√Kₜ) Or: Cₜ₊₁ = β · Cₜ/√Kₜ (equation 10.1)

The Euler equation equates the marginal utility of consuming today to the discounted marginal utility of investing and consuming tomorrow.

Constant Savings Rate Solution

Guess: Kₜ = s · F(K_{t−1}) = s · 2√K_{t−1} (constant fraction s of output is saved). Then Cₜ = (1−s) · 2√K_{t−1}.

Substituting into the Euler equation gives: Kₜ = β√K_{t−1}. So s = β/2.

The difference equation Kₜ = β√K_{t−1} converges: lim_{t→∞} Kₜ = β². The steady state is K* = β².

Economic Interpretation
The optimal savings rate is β/2. Higher β (more patient) → save more → higher steady state capital. The dynamics: starting at any K₀, the capital stock converges monotonically to K* = β². Consumption also converges to C* = 2β − β² = β(2−β).
Optimality of the Constant Savings Path

Define aₜ = Cₜ/(2√K_{t−1}) (fraction of output consumed in period t). With a₀ = 1−s = 1−β/2:

aₜ₊₁ = β · aₜ(1−aₜ) / [(1−aₜ)] + aₜ(1−β) [from Euler + feasibility]

Any path with a₀ ≠ 1−β/2 either violates feasibility eventually (Cₜ < 0 or Kₜ < 0) or converges to a path that is dominated. Only a₀ = 1−β/2 generates the optimal program for all t.

Section 2 — General DP Theory: Lemmas and Value Function
Assumptions 1–4 (from Lecture 9)
  1. X is compact, G : X → X has closed graph, G(x) ≠ ∅ for all x
  2. u : A → ℝ is continuous and bounded: |u| ≤ b
  3. 0 < β < 1
  4. For each x₀ ∈ X, ∃ a feasible program from x₀
Lemma 10.3 — Converse of Max-max
max_{y ∈ Y} max_{z ∈ Z} f(y,z) = max_{(y,z): y∈Y, z∈Z} f(y,z). This allows us to "unpack" nested maximizations — used extensively in proving V satisfies Bellman.
Existence of Optimal Program (Theorem 9.8, proven in Lec 10)
Under Assumptions 1–4, the value function V satisfies the Bellman equation and the optimal program exists (can be constructed by sequential greedy maximization of u(xₜ,xₜ₊₁) + βV(xₜ₊₁)).
Lecture 11

Dynamic Programming III: Contraction Mapping Theorem, Existence and Uniqueness of Value Function

Section 1 — Uniqueness of the Value Function
Theorem 11.1 — V is the Unique Bounded Solution to Bellman
Suppose F : X → ℝ is bounded and satisfies the Bellman equation: F(x₀) = max_{x₁ ∈ G(x₀)} [u(x₀,x₁) + βF(x₁)] for all x₀. Then F = V.
Proof sketch: Use the Bellman equation to build a program (x₀,x₁,x₂,…) that maximizes F. Show this program achieves V(x₀). Key: F(xₜ) satisfies the Bellman equation at each step, so by induction F(x₀) = Σᵀₜ₌₀ βᵗu(xₜ,xₜ₊₁) + β^{T+1}F(x_{T+1}). Take T→∞; the last term → 0 (since F is bounded and β<1), so F(x₀) = V(x₀). ∎
Section 2 — Contraction Mapping Theorem
Definition: Metric Space and Norm
A metric space (M,d) is a set M with a distance function d : M×M → ℝ₊ satisfying: d(x,y) ≥ 0; d(x,y)=0 iff x=y; d(x,y)=d(y,x); d(x,z) ≤ d(x,y)+d(y,z) (triangle inequality). The set of bounded functions f : X → ℝ with sup-norm ‖f‖ = sup_{x∈X}|f(x)| is a metric space.
Definition: Contraction Mapping
T : M → M is a contraction mapping with modulus β ∈ (0,1) if d(T(x),T(y)) ≤ β d(x,y) for all x,y ∈ M.
Contraction Mapping Theorem (Banach Fixed Point)
If (M,d) is a complete metric space (every Cauchy sequence converges) and T : M → M is a contraction mapping with modulus β < 1, then ∃ unique x* ∈ M with T(x*)=x* (a fixed point). Moreover, for any x₀ ∈ M, the sequence x_{n+1} = T(xₙ) converges to x* and d(xₙ,x*) ≤ βⁿ/(1−β) · d(x₁,x₀).
Why This Proves V Exists
Define the Bellman operator T by (Tf)(x₀) = max_{x₁ ∈ G(x₀)} [u(x₀,x₁) + βf(x₁)]. Show T is a contraction on the space of bounded continuous functions (with sup-norm). The Contraction Mapping Theorem guarantees a unique fixed point V = TV. This V is continuous (T maps continuous functions to continuous functions), bounded, and satisfies the Bellman equation. No need for the program to be differentiable or explicitly computable.
T is a Contraction (Blackwell's Conditions)
The Bellman operator T satisfies two conditions sufficient for being a contraction:
  1. Monotonicity: If f ≤ g pointwise, then Tf ≤ Tg.
  2. Discounting: T(f+c) ≤ Tf + βc for any constant c ≥ 0.
Together these imply T is a contraction with modulus β.
Algorithm: Value Function Iteration
  1. Start with any bounded function V₀ (e.g., V₀ ≡ 0)
  2. Compute Vₙ₊₁ = T(Vₙ) repeatedly
  3. By the Contraction Mapping Theorem, Vₙ → V in sup-norm at rate βⁿ
This is computable when X is finite or discretizable. The policy function π(x) = argmax_{y∈G(x)} [u(x,y) + βV(y)] is the optimal decision rule.
Significance for Macro/Trade
Dynamic programming and the Bellman equation are the foundation of modern macroeconomics (recursive competitive equilibrium, Bewley heterogeneous agent models, Stokey-Lucas theory of optimal growth) and trade theory (dynamic models of firm entry, technology adoption). The contraction mapping theorem guarantees these models are well-posed with unique value functions.
Section 3 — Properties of the Value Function and Policy
Key Properties Under Additional Assumptions
  • If u is continuous and G has closed graph, V is continuous
  • If u is strictly concave and G is convex-valued, V is strictly concave and the policy function π is a function (not a correspondence)
  • If u and G are differentiable, V is differentiable and Benveniste-Scheinkman formula gives V'(x₀) = ∂L/∂x₀ evaluated at the optimum (an envelope theorem for DP)
Growth Model Revisited
For the growth model with u = ln(C), F(K) = 2√K: the value function is V(K) = A + B ln(K) for constants A,B. Substituting into the Bellman equation gives a system for A and B. The policy function is K' = β/2 · F(K) = β√K (save fraction β/2 of output). The contraction mapping theorem guarantees this solution is unique.
